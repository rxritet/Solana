# Solana Wallet CLI

Учебная CLI-программа на Rust для задания «Rust для Solana-разработчика».

Программа моделирует тестовый кошелёк Solana в сети Devnet: показывает данные
кошелька, выполняет тестовые переводы, проверяет сумму и сохраняет историю
операций в памяти на время запуска.

## Запуск

```powershell
cd "E:\Homework\IT-Startup\2 week\solana-wallet-cli"
cargo run
```

## Возможности

- просмотр владельца, сети и баланса;
- выбор Devnet или Mainnet Beta;
- тестовый перевод в Devnet с проверкой адреса, суммы и баланса;
- история операций;
- обработка ошибочного ввода.

## Использованные конструкции Rust

- `struct` — модели `Wallet` и `Transaction`;
- `enum` и `match` — выбор и обработка сетей, а также пунктов меню;
- `Vec<Transaction>` — хранение истории операций;
- `Result` — обработка ошибок ввода и перевода;
- `impl` и методы — логика кошелька.

## Важно

Это локальный симулятор для обучения. Он не подключается к блокчейну, не
запрашивает приватные ключи и не переводит настоящие SOL.
